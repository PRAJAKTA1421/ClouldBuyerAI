# Kill Switch

A Flask landing page prototype for protecting autonomous AI-agent wallets.

## Run locally

```powershell
.venv\Scripts\Activate.ps1
python app.py
```

Open `http://127.0.0.1:5000` in your browser.

## Pages

- `/` — Kill Switch landing page and product features
- `/login` — Login page
- `/register` — Registration page

## Project structure

```text
app.py                  Flask routes
templates/index.html    Landing page
templates/auth.html     Login and registration page
static/style.css        All responsive styling
static/script.js        Form interactions
```
